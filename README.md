# Исследование токенизации русского текста

Учебный проект по обучению собственного BPE-токенизатора и сравнению его с готовым промышленным токенизатором русского языка.

## Цель работы

Изучить принципы субсловной токенизации, обучить собственный BPE-токенизатор на русскоязычном корпусе и оценить качество разбиения сложных слов по сравнению с RuBERT.

## Что реализовано

- Загрузка русскоязычных текстов из датасета `Helsinki-NLP/opus_books` (`en-ru`).
- Предварительная очистка текста: HTML-сущности, Unicode-нормализация, управляющие символы и лишние пробелы.
- Генератор текстов и пакетная передача данных для обучения.
- Настройка BPE с предварительным разбиением по пробелам и пунктуации.
- Обучение токенизатора со словарём до 16 000 токенов.
- Сохранение обученного токенизатора в JSON и проверка его повторной загрузки.
- Сравнение с `cointegrated/rubert-tiny2` на восьми тестовых предложениях.

## Используемые технологии

Python 3.12, Hugging Face `datasets`, `tokenizers`, `transformers`, Jupyter Notebook и `uv`.

## Запуск

Установить зависимости:

```bash
uv sync
```

Открыть учебный Jupyter Notebook и последовательно выполнить ячейки.

Для повторного использования обученного токенизатора:

```python
from tokenizers import Tokenizer

tokenizer = Tokenizer.from_file("bpe_tokenizer.json")
print(tokenizer.encode("Привет, мир!").tokens)
```

## Основные результаты

| Метрика | Собственный BPE | RuBERT |
|---|---:|---:|
| Количество тестовых предложений | 8 | 8 |
| Суммарное количество токенов | 155 | 104 |
| Среднее количество токенов на предложение | 19,38 | 13,00 |

RuBERT сформировал более компактное представление тестовых предложений. Собственный BPE в отдельных случаях удачно выделял морфологически узнаваемые фрагменты, но чаще дробил редкие слова, имена собственные и технические термины.
